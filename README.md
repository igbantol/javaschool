# Java School Projects

Some Java projects I made for school. Nothing too fancy but they work.

## Projects

### Hello
My first Java program ever. Just prints "Hello, World!" and a second line. Classic starter project.

**File:** `1st Quarter/Hello.java`

### Calendar App
A desktop calendar app I built with Java Swing. Lets you pick dates and add events to them.

**What it does:**
- Shows a full monthly calendar with arrows to go back/forward and a Today button
- Click a date to select it, double-click to add an event
- Right-click events to delete them
- Saves everything to a file in your home folder so events stay between runs
- Highlights today in blue, shows a red bar on dates that have events

**File:** `Calendar/CalendarApp/CalendarApp.java`

## How to run

Make sure you have Java installed (version 8 or newer should work).

```sh
# Hello
cd "1st Quarter"
javac Hello.java
java Hello

# Calendar App
cd Calendar/CalendarApp
javac CalendarApp.java
java CalendarApp
```
